# 🎫 Ticket Bot

Discord бот для управления тикетами с поддержкой слеш-команд.

## 📋 Команды

### 👤 Для всех
- `/help` - Помощь

### 👥 Для персонала
- `/close` - Закрыть тикет
- `/extend` - Продлить тикет

### 🛠️ Для администраторов
- `/setup` - Создать кнопки
- `/stats` - Статистика
